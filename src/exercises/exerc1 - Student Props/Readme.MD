# Exercício de Props

## ✅ Requisitos do Teste `Student.test.jsx`

1. [ ] O componente deve exibir corretamente o `name` passado como prop.
2. [ ] O componente deve exibir corretamente a `idade` no formato `Idade: {age}`.
3. [ ] O componente deve exibir corretamente o `email` passado como prop.
4. [ ] O componente deve exibir corretamente o `course` passado como prop.
5. [ ] Se **nenhum `name` for passado**, o componente deve exibir `"Aluno"` como nome padrão.

Documentação: https://react.dev/learn/passing-props-to-a-component
